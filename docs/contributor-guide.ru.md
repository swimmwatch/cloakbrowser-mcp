## Обязательная проверка на местном уровне

```bash
npm run check
```

Перед фиксацией изменений запустите полную проверку. Проверка на совместимость с Docker более ресурсоемкая и запускается следующим образом:

```bash
npm run docker:build
npm run bridge:compare -- cloakbrowser-mcp:dev --report bridge-parity-report.json
```

Проверку метаданных и зависимостей сборки можно запустить напрямую с помощью:

```bash
npm run server:validate
npm run audit:prod
```
