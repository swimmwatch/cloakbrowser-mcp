# Гуманізована поведінка при введенні даних

Функція імітації поведінки користувача спрямовує взаємодію зі сторінкою через
шар CloakBrowser, що імітує дії миші, клавіатури та прокрутки, як у людини. Це корисно, коли фахівцям з контролю якості потрібні більш
реалістичні темпи роботи, рух курсора, ритм набору тексту та поведінка прокрутки, ніж
ті, що забезпечує стандартна автоматизація.

Цей міст не додає нових інструментів браузера та не змінює вихідні схеми Playwright MCP.
Він застосовує патч CloakBrowser для взаємодії зі сторінками під час ініціалізації сторінки Playwright MCP,
тож існуючі інструменти продовжують працювати з тими самими вхідними даними.

## Що зміниться

Коли `CLOAK_PLAYWRIGHT_MCP_HUMANIZE=true`, CloakBrowser може надати більш природний вигляд типовим діям на сторінці,
зокрема:

- рухи миші та клацання;
- набір тексту на клавіатурі та натискання клавіш;
- заповнення форм та перехід між полями;
- прокрутка та перехід до певного елемента.

Це впливає на час взаємодії та схеми переміщення. Це не змінює
вміст сторінки, маршрутизацію мережі, налаштування проксі-сервера або геолокацію браузера.

## Загальні налаштування

Використовуйте цю змінну середовища, коли кожна сесія stdio або сесія Streamable HTTP за замовчуванням
повинна працювати у зручному для користувача режимі:

```bash
CLOAK_PLAYWRIGHT_MCP_HUMANIZE=true \
CLOAK_PLAYWRIGHT_MCP_HUMAN_PRESET=careful \
npx -y cloakbrowser-mcp@latest
```

Ця ж настройка працює і з явним параметром командного рядка:

```bash
npx -y cloakbrowser-mcp@latest --humanize --human-preset careful
```

## Налаштування Docker

Передайте ту саму змінну середовища в контейнер:

```bash
docker run --rm --init -i \
  -e CLOAK_PLAYWRIGHT_MCP_HUMANIZE=true \
  -e CLOAK_PLAYWRIGHT_MCP_HUMAN_PRESET=careful \
  -v "$PWD/artifacts:/data" \
  swimmwatch/cloakbrowser-mcp:latest
```

Для Streamable HTTP у Docker ця змінна середовища стає значенням за замовчуванням для
нових сеансів HTTP:

```bash
docker run --rm --init -p 127.0.0.1:3000:3000 \
  -e CLOAK_PLAYWRIGHT_MCP_HUMANIZE=true \
  -e CLOAK_PLAYWRIGHT_MCP_HUMAN_PRESET=careful \
  -v "$PWD/artifacts:/data" \
  swimmwatch/cloakbrowser-mcp:latest \
  --transport streamable-http --http-host 0.0.0.0 --http-port 3000
```

## Налаштування потокового HTTP для окремої сесії

HTTP-клієнти, що підтримують потокову передачу даних, можуть вибрати «людську» модель поведінки під час
ініціалізації сеансу MCP. Це дозволяє одному серверу порівнювати стандартну та «людську»
моделі взаємодії без необхідності його перезапуску.

Надіслати метадані мосту у запиті `initialize`:

```json
{
  "params": {
    "_meta": {
      "io.github.swimmwatch/cloakbrowser-mcp": {
        "humanize": true,
        "humanPreset": "careful"
      }
    }
  }
}
```

`humanize` замінює налаштування на рівні процесу для цієї HTTP-сесії. Використовуйте
`true` для увімкнення «людської» поведінки або `false`, щоб вимкнути його, навіть якщо
сервер було запущено з параметром `CLOAK_PLAYWRIGHT_MCP_HUMANIZE=true`.

`humanPreset` приймає `default` або `careful` та обирає пресет поведінки людини
CloakBrowser для сеансу. Сама по собі вона не вмикає гуманізовану поведінку;
для цього встановіть `humanize: true` або увімкніть `CLOAK_PLAYWRIGHT_MCP_HUMANIZE=true`.
Пресет `careful` працює повільніше та обережніше, ніж `default`.

Існуючі сесії HTTP є незмінними. Створіть ще одну сесію HTTP типу Streamable, щоб
перемикатися між стандартною та «людською» поведінкою.

  Порівнюйте стандартну автоматизацію з людиноподібною взаємодією, коли сторінка
  по-різному реагує на дуже швидке або ідеально лінійне введення.

## Пріоритет та обмеження

| Область | Поведінка |
| --- | --- |
| Stdio | Використовує лише змінні середовища та прапорці CLI рівня процесу. |
| Типове значення Streamable HTTP | Використовує змінні середовища та прапорці CLI рівня процесу, якщо метадані runtime не передано. |
| Метадані Streamable HTTP | `initialize.params._meta["io.github.swimmwatch/cloakbrowser-mcp"].humanize` може перевизначити людиноподібну поведінку для одного сеансу. `humanPreset` може вибрати `default` або `careful`. |
| Існуючі сеанси | Зберігають налаштування humanize, зафіксоване під час `initialize`. |
| Браузерний рушій | Застосовується лише при `PLAYWRIGHT_MCP_BROWSER_ENGINE=cloak`. |
| Схеми інструментів | Схеми браузерних інструментів upstream Playwright MCP залишаються без змін. |
| Користувацька конфігурація | `humanConfig` навмисно поки не приймається; структурованій конфігурації потрібна явна схема валідації. |

Ця функція призначена для проведення законного контролю якості, перевірки реалістичності взаємодії та узгодженості.
Її не слід розглядати як спосіб обходу засобів контролю доступу або перевірок дотримання
політики.
