# Поведение ввода с учетом человеческих особенностей

Функция «гуманизированного ввода» направляет взаимодействия со страницей через
слой CloakBrowser, имитирующий действия мыши, клавиатуры и прокрутки, характерные для человека. Это полезно в тех случаях, когда специалистам по контролю качества требуется более
реалистичный темп работы, движение указателя, ритм набора текста и поведение прокрутки, чем
предусматривает стандартная автоматизация.

Мост не добавляет новых инструментов браузера и не изменяет исходные схемы Playwright MCP.
Он применяет патч CloakBrowser для взаимодействия со страницами во время инициализации страницы Playwright MCP,
поэтому существующие инструменты продолжают работать с теми же входными данными.

## Что изменится

Когда `CLOAK_PLAYWRIGHT_MCP_HUMANIZE=true`, CloakBrowser может сделать стандартные действия на странице
более интуитивными, в том числе:

- движения мыши и щелчки;
- набор текста с клавиатуры и нажатия клавиш;
- заполнение форм и переход между полями;
- прокрутка и переход к элементу при прокрутке.

Это влияет на временные параметры взаимодействия и схемы перемещения. При этом не изменяется
содержание страницы, маршрутизация в сети, настройки прокси-сервера или геолокация браузера.

## Глобальные настройки

Используйте переменную среды, если для каждого сеанса stdio или сеанса Streamable HTTP по умолчанию
необходимо применять «удобное для пользователя» поведение:

```bash
CLOAK_PLAYWRIGHT_MCP_HUMANIZE=true \
CLOAK_PLAYWRIGHT_MCP_HUMAN_PRESET=careful \
npx -y cloakbrowser-mcp@latest
```

Эта же настройка работает с явным флагом командной строки:

```bash
npx -y cloakbrowser-mcp@latest --humanize --human-preset careful
```

## Настройка Docker

Передайте ту же переменную среды в контейнер:

```bash
docker run --rm --init -i \
  -e CLOAK_PLAYWRIGHT_MCP_HUMANIZE=true \
  -e CLOAK_PLAYWRIGHT_MCP_HUMAN_PRESET=careful \
  -v "$PWD/artifacts:/data" \
  swimmwatch/cloakbrowser-mcp:latest
```

В случае Streamable HTTP в Docker эта переменная среды становится значением по умолчанию для
новых HTTP-сессий:

```bash
docker run --rm --init -p 127.0.0.1:3000:3000 \
  -e CLOAK_PLAYWRIGHT_MCP_HUMANIZE=true \
  -e CLOAK_PLAYWRIGHT_MCP_HUMAN_PRESET=careful \
  -v "$PWD/artifacts:/data" \
  swimmwatch/cloakbrowser-mcp:latest \
  --transport streamable-http --http-host 0.0.0.0 --http-port 3000
```

## Настройка потокового HTTP для отдельного сеанса

HTTP-клиенты с поддержкой потоковой передачи данных могут выбрать «человекоподобное» поведение на этапе
инициализации сеанса MCP. Это позволяет одному серверу сравнивать стандартное и «человекоподобное»
поведение при взаимодействии без необходимости его перезапуска.

Отправьте метаданные моста в запросе `initialize`:

```json
{
  "params": {
    "_meta": {
      "io.github.swimmwatch/cloakbrowser-mcp": {
        "humanize": true,
        "humanPreset": "careful"
      }
    }
  }
}
```

`humanize` переопределяет настройку на уровне процесса для данного HTTP-сеанса. Используйте
`true` для включения «гуманизированного» поведения или `false`, чтобы отключить его, даже если
сервер был запущен с параметром `CLOAK_PLAYWRIGHT_MCP_HUMANIZE=true`.

`humanPreset` принимает `default` или `careful` и выбирает для сеанса предустановку
поведения человека в CloakBrowser. Сам по себе он не включает гуманизированное поведение;
для этого установите `humanize: true` или включите `CLOAK_PLAYWRIGHT_MCP_HUMANIZE=true`.
Предустановка `careful` работает медленнее и более осторожно, чем `default`.

Существующие HTTP-сессии являются неизменяемыми. Создайте ещё одну HTTP-сессию Streamable, чтобы
переключаться между стандартным и «человекоподобным» поведением.

## Варианты использования

<div class="grid cards" markdown>

- :material-form-textbox: **QA форм**

  Проверяйте ввод текста, заполнение, смену фокуса и сценарии валидации с более
  реалистичным ритмом клавиатуры.

- :material-cart-check: **Сценарии оформления заказа**

  Тестируйте насыщенные взаимодействиями пути покупки, где скорость ввода, кликов и
  переключения полей может влиять на клиентскую валидацию.

- :material-shield-search: **Проверки UI, чувствительного к взаимодействию**

  Сравнивайте стандартную автоматизацию с человекоподобным взаимодействием, когда страница
  по-разному реагирует на слишком быстрый или идеально линейный ввод.

- :material-mouse-scroll-wheel: **Страницы с активной прокруткой**

  Проверяйте длинные страницы, ленты, списки товаров и lazy-loading контент с
  более плавным поведением прокрутки.

- :material-presentation-play: **Демонстрации и записи**

  Создавайте браузерные сеансы, которые выглядят менее механическими во время product demo,
  walkthrough или записи QA-доказательств.

</div>

## Приоритет и ограничения

| Область | Поведение |
| --- | --- |
| Stdio | Использует только переменные среды и флаги CLI уровня процесса. |
| Значение по умолчанию Streamable HTTP | Использует переменные среды и флаги CLI уровня процесса, если метаданные runtime не переданы. |
| Метаданные Streamable HTTP | `initialize.params._meta["io.github.swimmwatch/cloakbrowser-mcp"].humanize` может переопределить человекоподобное поведение для одного сеанса. `humanPreset` может выбрать `default` или `careful`. |
| Существующие сеансы | Сохраняют настройку humanize, зафиксированную во время `initialize`. |
| Браузерный движок | Применяется только при `PLAYWRIGHT_MCP_BROWSER_ENGINE=cloak`. |
| Схемы инструментов | Схемы браузерных инструментов upstream Playwright MCP остаются без изменений. |
| Пользовательская конфигурация | `humanConfig` намеренно пока не принимается; структурированной конфигурации нужна явная схема валидации. |

Данная функция предназначена для проведения законного контроля качества, проверки реалистичности взаимодействия и обеспечения согласованности.
Её не следует рассматривать как способ обхода средств контроля доступа или проверок
соответствия политикам.
