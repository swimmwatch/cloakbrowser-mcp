# @playwright/mcp против cloakbrowser-mcp

Исходный `@playwright/mcp` — основной сервер браузерных инструментов Playwright MCP. `cloakbrowser-mcp` предназначен для команд, которым нужен тот же набор инструментов с Chromium от CloakBrowser и готовыми способами развёртывания.

## Сравнение возможностей

| Возможность | `@playwright/mcp` | `cloakbrowser-mcp` |
| --- | --- | --- |
| Исходные инструменты без изменений | Определяет исходные схемы, описания и ответы браузерных инструментов. | Пересылает исходные браузерные инструменты без изменений и проверяет их соответствие в CI. |
| Бинарный файл CloakBrowser | Использует браузер, выбранный исходным Playwright MCP. | Создаёт конфигурацию upstream с Chromium от CloakBrowser в качестве исполняемого файла. |
| Поставка через npm | Публикуется как исходный пакет Playwright MCP. | Публикуется как `cloakbrowser-mcp` для `npx` и настроек stdio клиентов MCP. |
| Образ Docker | Предоставляет официальный образ Playwright MCP. | Собирается на основе официального образа Playwright MCP и подготавливает настройки среды CloakBrowser по умолчанию. |
| Streamable HTTP | Использует поведение транспорта исходного проекта. | Предоставляет stdio и Streamable HTTP с проверками состояния и готовности, авторизацией, HTTPS и метаданными сеансов. |
| Постоянные профили | Использует поддерживаемые upstream параметры состояния браузера. | Добавляет проверку `PLAYWRIGHT_MCP_USER_DATA_DIR` и блокировку профиля при формировании конфигурации. |
| Пути расширений | Настраиваются средствами браузера, если он это поддерживает. | Добавляет загрузку проверенных каталогов расширений Chrome с требованием постоянного профиля. |
| Проверка контекста | Зависит от структуры конфигурации upstream. | Проверяет поддерживаемые параметры контекста перед записью конфигурации Playwright MCP. |
| Региональные проверки с GeoIP | Маршрутизация через прокси остаётся ответственностью upstream. | Может согласовать часовой пояс, язык и локаль отпечатка CloakBrowser с местоположением настроенного прокси. |
| Человекоподобное взаимодействие | Использует стандартное поведение взаимодействий Playwright MCP. | Может направлять поддерживаемые взаимодействия со страницей через человекоподобный ввод CloakBrowser. |

## Когда выбрать исходный Playwright MCP

- Вам нужна минимально возможная установка Playwright MCP.
- Вам не нужен CloakBrowser Chromium.
- Вы предпочитаете напрямую следить за упаковкой upstream Playwright MCP.

## Когда выбрать CloakBrowser MCP

- Для работы с CloakBrowser Chromium необходимы инструменты upstream Playwright MCP.
- Вы хотите, чтобы пути развертывания npm, Docker и Streamable HTTP были задокументированы в одном пакете.
- Вам нужны постоянные профили входа, загрузка расширений, проверка контекста, региональные помощники QA или гуманизированное поведение ввода.
