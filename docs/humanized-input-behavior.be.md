# Гуманізаваная паводзіна ўводу

Паводзіны ўваходу з імітацыяй чалавека накіроўваюць узаемадзеянне са старонкамі праз пласт мышы, клавіятуры і пракруткі CloakBrowser, які імітуе чалавека. Гэта карысна, калі для аддзела кантролю якасці (QA) патрэбны больш рэалістычны тэмп, рух курсора, рытм набору і паводзіны пры пракрутцы, чым прапануе стандартная аўтаматызацыя.

Мост не дадае новых інструментаў для браўзера і не змяняе схемы Playwright MCP у вышэйшым патоку. Ён прымяняе патч CloakBrowser для ўзаемадзеяння са старонкай падчас ініцыялізацыі старонкі Playwright MCP, таму існуючыя інструменты працягваюць працаваць з тымі ж уваходнымі данымі.

## Што гэта мяняе

Калі `CLOAK_PLAYWRIGHT_MCP_HUMANIZE=true`, CloakBrowser можа зрабіць больш чалавечнымі звычайныя дзеянні на старонцы, у тым ліку:

- перамяшчэнне мышы і пстрычкі;
- набор на клавіятуры і націсканне клавіш;
- запаўненне форм і пераключэнне палёў;
- пракрутка і паводзіны пры пракрутцы да элемента.

Гэта ўплывае на часы ўзаемадзеяння і заканамернасці руху. Гэта не змяняе змест старонкі, маршрутызацыю сеткі, налады праксі-сервера або геалакацыю браўзера.

## Сусветныя налады

Выкарыстоўвайце зменную асяроддзя, калі кожная сесія stdio або стандартная HTTP-сесія Streamable павінна выкарыстоўваць гуманізаваную паводзіны:

```bash
CLOAK_PLAYWRIGHT_MCP_HUMANIZE=true \
CLOAK_PLAYWRIGHT_MCP_HUMAN_PRESET=careful \
npx -y cloakbrowser-mcp@latest
```

Тое ж самае наладжванне працуе з адкрытым сцягам CLI:

```bash
npx -y cloakbrowser-mcp@latest --humanize --human-preset careful
```

## Наладка Docker

Перадайце тую ж зменную асяроддзя кантэйнеру:

```bash
docker run --rm --init -i \
  -e CLOAK_PLAYWRIGHT_MCP_HUMANIZE=true \
  -e CLOAK_PLAYWRIGHT_MCP_HUMAN_PRESET=careful \
  -v "$PWD/artifacts:/data" \
  swimmwatch/cloakbrowser-mcp:latest
```

Для Streamable HTTP у Docker зменная асяроддзя становіцца значэннем па змаўчанні для новых HTTP-сеансаў:

```bash
docker run --rm --init -p 127.0.0.1:3000:3000 \
  -e CLOAK_PLAYWRIGHT_MCP_HUMANIZE=true \
  -e CLOAK_PLAYWRIGHT_MCP_HUMAN_PRESET=careful \
  -v "$PWD/artifacts:/data" \
  swimmwatch/cloakbrowser-mcp:latest \
  --transport streamable-http --http-host 0.0.0.0 --http-port 3000
```

Налада HTTP для струменевых сеансаў

Падчас ініцыялізацыі сеансу MCP кліенты HTTP, якія падтрымліваюць Streamable, могуць выбраць гуманізаванае паводзіны. Гэта дазваляе аднаму серверу параўнаць стандартныя і гуманізаваныя паводзіны ўзаемадзеяння без перазапуску.

Дашліце метаданыя моста ў запыце `initialize`:

```json
{
  "params": {
    "_meta": {
      "io.github.swimmwatch/cloakbrowser-mcp": {
        "humanize": true,
        "humanPreset": "careful"
      }
    }
  }
}
```

`humanize` перавышае налады ўзроўню працэсу для гэтай HTTP-сесіі. Выкарыстоўвайце `true` для ўключэння гуманізаванага паводзін або `false` для адключэння яго нават калі сервер быў запушчаны з `CLOAK_PLAYWRIGHT_MCP_HUMANIZE=true`.

`humanPreset` прымае `default` або `careful` і выбірае папярэднюю наладку чалавечага паводзін CloakBrowser для сеансу. Гэта не ўключае антропоіднае паводзіны само па сабе; усталяваць `humanize: true` або ўключыць `CLOAK_PLAYWRIGHT_MCP_HUMANIZE=true`.
Прыстасаванне `careful` больш павольнае і асцярожнае, чым `default`.

Існуючыя HTTP-сесіі незваротныя. Стварыце яшчэ адну Streamable HTTP-сесію, каб пераключацца паміж стандартным і зразумелым для чалавека паводзінамі.

## Прыярытэты і абмежаванні

| Вобласць | Паводзіны |
| --- | --- |
| Stdio | Выкарыстоўвае толькі зменныя асяроддзя і флагі CLI на ўзроўні працэсу. |
| Значэнне па змаўчанні Streamable HTTP | Выкарыстоўвае зменныя асяроддзя і флагі CLI на ўзроўні працэсу, калі метаданыя runtime не перададзены. |
| Метаданыя Streamable HTTP | `initialize.params._meta["io.github.swimmwatch/cloakbrowser-mcp"].humanize` можа пераазначыць чалавекападобныя паводзіны для аднаго сеанса. `humanPreset` можа выбраць `default` або `careful`. |
| Існыя сеансы | Захоўваюць наладу humanize, зафіксаваную падчас `initialize`. |
| Браузерны рухавік | Ужываецца толькі пры `PLAYWRIGHT_MCP_BROWSER_ENGINE=cloak`. |
| Схемы інструментаў | Схемы браузерных інструментаў upstream Playwright MCP застаюцца без змен. |
| Карыстальніцкая канфігурацыя | `humanConfig` наўмысна пакуль не прымаецца; структураванай канфігурацыі патрэбна яўная схема валідацыі. |

Гэтая функцыя прызначана для законнага тэсціравання якасці (QA), рэалізму ўзаемадзеяння і сумяшчальнасці. Яе нельга разглядаць як спосаб абыходу кантролю доступу або праверкі палітыкі.
