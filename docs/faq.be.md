# Частыя пытанні

## Што такое CloakBrowser MCP?

CloakBrowser MCP — гэта сервер [Пратакола кантэксту мадэлі](https://modelcontextprotocol.io/) для аўтаматызацыі браўзера праз stdio або Streamable HTTP. Ён запускае upstream [`@playwright/mcp`](https://github.com/microsoft/playwright-mcp) і накіроўвае канфігурацыю запуску браўзера Playwright MCP на бінарнік Chromium [CloakBrowser](https://github.com/CloakHQ/CloakBrowser).

## У чым розніца з upstream Playwright MCP?

Сервер Playwright MCP кіруе схемамі, апісаннямі і адказамі інструментаў для браўзера. CloakBrowser MCP захоўвае гэтыя інструменты без змен і дадае толькі два мясцовыя інструменты інтраспекцыі: `cloakbrowser_binary_info` і `cloakbrowser_bridge_info`.

## Ці варта ўсталёўваць яго з npm ці Docker?

Выкарыстоўвайце npm, калі ваш кліент MCP ужо запушчаны на вашым камп'ютары і даступны Node.js 22.12 або навейшы. Выкарыстоўвайце Docker, калі вы хочаце атрымаць паўторны образ на аснове Playwright MCP з кэшам CloakBrowser, падрыхтаваным у кантэйнеры.

## Якія кліенты MCP могуць яго выкарыстоўваць?

Любы кліент MCP, які падтрымлівае stdio або серверы Streamable HTTP, можа выкарыстоўваць CloakBrowser MCP. [Пачатак працы](getting-started.md) кіраўніцтва змяшчае прыклады JSON для stdio для Codex, Claude Desktop, Claude Code, Cursor, кліентаў у стылі VS Code/Cline, Continue, Windsurf, Goose і канфігурацый у стылі Warp.

## Ці падтрымлівае ён тыя ж інструменты браўзера, што і Playwright MCP?

Так. Інструменты для браўзера з рэпазіторыя upstream Playwright MCP перадаюцца без змен. Праект таксама запускае параўнальны аналіз парытэту ў CI, таму змены ў мосце можна правяраць на адпаведнасць афіцыйнаму паводжанню Playwright MCP.

## Ці паляпшае Docker бяспеку?

Docker забяспечвае больш паўтаральнае і ізаляванае асяроддзе выканання, але гэта не робіць аўтаматызацыю ў браўзеры бясризыкоўнай. Стаўцеся да аўтаматызаванага прагляду як да недаверлівага выканання: пазбягайце перадачы сакрэтаў невядомым старонкам, захоўвайце артыфакты і скрыншоты ў кантраляваных каталогах і азнаёмцеся з кіраўніцтвам [Security](security.md) перад падключэннем сервера да іншых сістэм.
