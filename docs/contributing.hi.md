# योगदान

पुल रिक्वेस्ट खोलने से पहले स्थानीय जांचें चलाएँ और ब्रिज आर्किटेक्चर पेज पढ़ें।

```bash
npm install
npm run check
```

पुल रिक्वेस्ट चेकलिस्ट

- [ ] `npm run check` पास हो गए हैं।
- [ ] नए ब्रिज व्यवहार के लिए परीक्षण हैं।
- [ ] अपस्ट्रीम प्लेराइट MCP स्कीमा, विवरण और प्रतिक्रियाएँ अपरिवर्तित रहती हैं।
- [ ] उपयोगकर्ता-दृश्यमान परिवर्तनों का दस्तावेजीकरण किया गया है।
- [ ] `CHANGELOG.md` को उपयोगकर्ता-दृश्यमान परिवर्तनों के लिए अपडेट किया गया है।
- [ ] सुरक्षा-संवेदनशील परिवर्तनों को PR विवरण में नोट किया गया है।

## परीक्षण रिपोर्ट

`test:report:generate` से बनाई गई स्थानीय रिपोर्ट स्वतंत्र HTML फ़ाइलें बनी रहती हैं। संयुक्त CI रिपोर्ट GitHub की फ़ाइल आकार सीमा से बचने के लिए HTML, JavaScript और डेटा को अलग-अलग फ़ाइलों में रखती हैं। पूरा `combined-test-report` आर्टिफ़ैक्ट डाउनलोड करके निकालें, फिर उसकी डायरेक्टरी खोलें:

```bash
npm run test:report:open -- --report /path/to/extracted-report
```

कई फ़ाइलों वाली रिपोर्ट के लिए यह कमांड इंस्टॉल किए गए Allure व्यूअर को शुरू करता है। रिपोर्ट देखते समय इसे चालू रखें; रोकने के लिए `Ctrl+C` दबाएँ। GitHub Pages पर प्रकाशन रिपोर्ट के संसाधनों को अलग रिपोर्ट रिपॉज़िटरी में सुरक्षित रखता है।

## न करें

- हटाए गए नेटिव ब्राउज़र एडाप्टर, टूल रजिस्ट्री, या कैपेबिलिटी मॉडल को फिर से न जोड़ें।
- रनटाइम लॉग `stdout` पर न लिखें; stdio MCP JSON-RPC के लिए आरक्षित है।
- कोई निर्भरता न जोड़ें जब तक कि उसे रनटाइम या परीक्षणों द्वारा आयात न किया गया हो।
- किसी बदलाव को पास कराने के लिए टाइपस्क्रिप्ट, ईएसलिंट, या प्रिटियर सेटिंग्स को कमजोर न करें।
- `dist/`, `coverage/`, `artifacts/`, `site/`, `.venv-docs/`, या `node_modules/`.
