# Кіраўніцтва для аўтараў

Карыстальніцкая дакументацыя наўмысна сканцэнтравана на ўсталёўцы і выкарыстанні сервера MCP. Матэрыялы для распрацоўкі згрупаваны тут.

## Раздзелы

- [Распрацоўка](development.md) для лакальнай наладкі і структуры пакета.
- [Тэсціраванне](testing.md) для праверкі адзінкавых кампанентаў, інтэграцыі, Docker, npm-пакетаў і параўнання.
- [Архітэктура](architecture.md) для распрацоўкі асяроддзя выканання маста.
- [Выпуск](release.md) для налад рэпазіторыя і працэсаў публікацыі.
- [Удзел](contributing.md) для працоўнага працэсу праекта.

## Абавязковая мясцовая праверка

```bash
npm run check
```

Правядзіце поўную праверку перад камітаваннем. Docker-парытэт больш рэсурсаёмісты і можа запускацца з дапамогай:

```bash
npm run docker:build
npm run bridge:compare -- cloakbrowser-mcp:dev --report bridge-parity-report.json
```

Метаданыя і праверкі залежнасцей вытворчасці можна запусціць непасрэдна з дапамогай:

```bash
npm run server:validate
npm run audit:prod
```
