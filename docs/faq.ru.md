# Часто задаваемые вопросы

## Что такое CloakBrowser MCP?

CloakBrowser MCP — это сервер [Model Context Protocol](https://modelcontextprotocol.io/) для автоматизации работы браузера через stdio или Streamable HTTP. Он запускается выше по цепочке [`@playwright/mcp`](https://github.com/microsoft/playwright-mcp) и настраивает конфигурацию запуска браузера Playwright MCP на бинарный файл [CloakBrowser](https://github.com/CloakHQ/CloakBrowser) на базе Chromium.

## Чем он отличается от исходной версии Playwright MCP?

Сервер Playwright MCP, расположенный выше по цепочке, управляет схемами, описаниями и ответами браузерных инструментов. CloakBrowser MCP оставляет эти инструменты без изменений и добавляет лишь два локальных инструмента интроспекции: `cloakbrowser_binary_info` и `cloakbrowser_bridge_info`.

## Устанавливать ли его через npm или Docker?

Используйте npm, если на вашем компьютере уже запущен клиент MCP и установлена версия Node.js 22.12 или более поздняя. Используйте Docker, если вам нужен воспроизводимый образ на базе Playwright MCP с кэшем CloakBrowser, подготовленным внутри контейнера.

## Какие клиенты MCP могут этим воспользоваться?

Любой клиент MCP, поддерживающий серверы stdio или Streamable HTTP, может использовать CloakBrowser MCP. В руководстве [«Начало работы»](getting-started.md) содержит примеры JSON-кода для stdio, предназначенные для Codex, Claude Desktop, Claude Code, Cursor, клиентов в стиле VS Code/Cline, Continue, Windsurf, Goose и конфигураций в стиле Warp.

## Поддерживает ли он те же инструменты браузера, что и Playwright MCP?

Да. Инструменты браузера Upstream Playwright MCP передаются без изменений. В рамках непрерывной интеграции (CI) также выполняется сравнение на соответствие, что позволяет проверять изменения в мосте на соответствие официальному поведению Playwright MCP.

## Повышает ли Docker уровень безопасности?

Docker обеспечивает более воспроизводимую и изолированную среду выполнения, но не делает автоматизацию работы браузера абсолютно безопасной. Относитесь к автоматизированному просмотру веб-страниц как к недоверенному выполнению: избегайте передачи секретных данных неизвестным страницам, храните артефакты и скриншоты в контролируемых каталогах и ознакомьтесь с руководством по [безопасности](security.md), прежде чем открывать доступ к серверу для других систем.

## Использует ли этот проект аналитику или средства отслеживания?

Нет. На сайте документации аналитика по умолчанию не включена. Поисковая оптимизация осуществляется с помощью стандартных метаданных, `robots.txt`, генерации карты сайта, дополнительных тегов для подтверждения веб-мастером и дополнительных уведомлений IndexNow.
