# @playwright/mcp супраць cloakbrowser-mcp

Зыходны `@playwright/mcp` — асноўны сервер браўзерных інструментаў Playwright MCP. `cloakbrowser-mcp` прызначаны для каманд, якім патрэбны той жа набор інструментаў з Chromium ад CloakBrowser і гатовымі спосабамі разгортвання.

## Параўнанне магчымасцяў

| Магчымасць | `@playwright/mcp` | `cloakbrowser-mcp` |
| --- | --- | --- |
| Зыходныя інструменты без змен | Вызначае зыходныя схемы, апісанні і адказы браўзерных інструментаў. | Перасылае зыходныя браўзерныя інструменты без змен і правярае іх адпаведнасць у CI. |
| Бінарны файл CloakBrowser | Выкарыстоўвае браўзер, выбраны зыходным Playwright MCP. | Стварае канфігурацыю upstream з Chromium ад CloakBrowser у якасці выканальнага файла. |
| Пастаўка праз npm | Публікуецца як зыходны пакет Playwright MCP. | Публікуецца як `cloakbrowser-mcp` для `npx` і налад stdio кліентаў MCP. |
| Вобраз Docker | Прадастаўляе афіцыйны вобраз Playwright MCP. | Збіраецца на аснове афіцыйнага вобраза Playwright MCP і рыхтуе стандартныя налады асяроддзя CloakBrowser. |
| Streamable HTTP | Выкарыстоўвае паводзіны транспарту зыходнага праекта. | Прадастаўляе stdio і Streamable HTTP з праверкамі стану і гатоўнасці, аўтарызацыяй, HTTPS і метаданымі сеансаў. |
| Пастаянныя профілі | Выкарыстоўвае падтрымліваемыя upstream параметры стану браўзера. | Дадае праверку `PLAYWRIGHT_MCP_USER_DATA_DIR` і блакаванне профілю пры стварэнні канфігурацыі. |
| Шляхі пашырэнняў | Наладжваюцца сродкамі браўзера, калі ён гэта падтрымлівае. | Дадае загрузку правераных каталогаў пашырэнняў Chrome з патрабаваннем пастаяннага профілю. |
| Праверка кантэксту | Залежыць ад структуры канфігурацыі upstream. | Правярае падтрымліваемыя параметры кантэксту перад запісам канфігурацыі Playwright MCP. |
| Рэгіянальныя праверкі з GeoIP | Маршрутызацыя праз проксі застаецца адказнасцю upstream. | Можа ўзгадніць часавы пояс, мову і лакаль адбітка CloakBrowser з месцазнаходжаннем наладжанага проксі. |
| Чалавекападобнае ўзаемадзеянне | Выкарыстоўвае стандартныя паводзіны ўзаемадзеянняў Playwright MCP. | Можа накіроўваць падтрымліваемыя ўзаемадзеянні са старонкай праз чалавекападобны ўвод CloakBrowser. |

## Калі выбраць зыходны Playwright MCP

- Вы хочаце мінімальную наладу Playwright MCP.
- Вам не патрэбны CloakBrowser Chromium.
- Вы аддаеце перавагу прытрымлівацца ўпакоўцы Playwright MCP уверх па плыні непасрэдна.

## Калі выбраць CloakBrowser MCP

- Для працы з CloakBrowser Chromium вам спатрэбяцца інструменты Playwright MCP уверх па плыні.
- Вы хочаце, каб шляхі разгортвання npm, Docker і Streamable HTTP дакументаваліся ў адным пакеце.
- Вам патрэбныя пастаянныя профілі ўваходу, загрузка пашырэнняў, праверка кантэксту, рэгіянальныя памочнікі QA або гуманізаванае паводзіны ўводу.
