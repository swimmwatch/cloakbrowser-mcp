# @playwright/mcp проти cloakbrowser-mcp

Вихідний `@playwright/mcp` — основний сервер браузерних інструментів Playwright MCP. `cloakbrowser-mcp` призначений для команд, яким потрібен той самий набір інструментів із Chromium від CloakBrowser та готовими способами розгортання.

## Порівняння можливостей

| Можливість | `@playwright/mcp` | `cloakbrowser-mcp` |
| --- | --- | --- |
| Вихідні інструменти без змін | Визначає вихідні схеми, описи та відповіді браузерних інструментів. | Пересилає вихідні браузерні інструменти без змін і перевіряє їх відповідність у CI. |
| Бінарний файл CloakBrowser | Використовує браузер, вибраний вихідним Playwright MCP. | Створює конфігурацію upstream із Chromium від CloakBrowser як виконуваним файлом. |
| Постачання через npm | Публікується як вихідний пакет Playwright MCP. | Публікується як `cloakbrowser-mcp` для `npx` і налаштувань stdio клієнтів MCP. |
| Образ Docker | Надає офіційний образ Playwright MCP. | Збирається на основі офіційного образу Playwright MCP і готує типові налаштування середовища CloakBrowser. |
| Streamable HTTP | Використовує поведінку транспорту вихідного проєкту. | Надає stdio та Streamable HTTP із перевірками стану й готовності, авторизацією, HTTPS і метаданими сеансів. |
| Постійні профілі | Використовує підтримувані upstream параметри стану браузера. | Додає перевірку `PLAYWRIGHT_MCP_USER_DATA_DIR` і блокування профілю під час створення конфігурації. |
| Шляхи розширень | Налаштовуються засобами браузера, якщо він це підтримує. | Додає завантаження перевірених каталогів розширень Chrome з вимогою постійного профілю. |
| Перевірка контексту | Залежить від структури конфігурації upstream. | Перевіряє підтримувані параметри контексту перед записом конфігурації Playwright MCP. |
| Регіональні перевірки з GeoIP | Маршрутизація через проксі залишається відповідальністю upstream. | Може узгодити часовий пояс, мову та локаль відбитка CloakBrowser із розташуванням налаштованого проксі. |
| Людиноподібна взаємодія | Використовує стандартну поведінку взаємодій Playwright MCP. | Може спрямовувати підтримувані взаємодії зі сторінкою через людиноподібне введення CloakBrowser. |

## Коли вибрати вихідний Playwright MCP

- Вам потрібно найменше можливе налаштування Playwright MCP.
- Вам не потрібен CloakBrowser Chromium.
- Ви віддаєте перевагу безпосередньо стежити за пакуванням Playwright MCP.

## Коли вибрати CloakBrowser MCP

- Вам потрібні вихідні інструменти Playwright MCP для запуску з CloakBrowser Chromium.
- Ви хочете, щоб шляхи розгортання npm, Docker та Streamable HTTP були задокументовані в одному пакеті.
- Вам потрібні постійні профілі входу, завантаження розширення, перевірка контексту, регіональні помічники QA або гуманізована поведінка введення.
