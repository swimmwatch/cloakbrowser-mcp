## Required Content

- Every CLI option and environment variable, including default values, independent CLI-over-environment precedence, `--no-cdp-enabled`, and `--no-cdp-allow-remote`.
- Stdio process-level enablement and the Streamable HTTP inheritance/override matrix for absent, true, and false `cdpEnabled`.
- Port-pool semantics: a pool alone does not enable CDP; one enabled session owns one external lease; process-local allocation and immediate external collision behavior.
- `--cdp-advertised-scheme`: `http` publishes http/ws; `https` publishes https/wss only.
- An explicit topology warning that the managed CDP listener and Chromium hop remain plaintext. For https/wss, the operator owns a TLS terminator on the advertised leased port, preserves Host/Origin authority, and maintains one-to-one session routing. The bridge does not create or validate TLS.
- Node stdio, multi-session Streamable HTTP, and Docker one-to-one range-publication examples. Examples must not imply that a disabled session consumes a port.
- `cloakbrowser_bridge_info.cdp` disabled, ready, and unavailable states; discovery URL credential handling; generation and active-connection meanings.
- `connectOverCDP()` usage and its distinction from Playwright Server `chromium.connect()`. State that the current Open WebUI direct flow remains unsupported.
- Eager browser bootstrap cost and at-least-60-second client initialize-timeout guidance.
- Internal loopback endpoint, retained Playwright pipe, ownership proof, per-generation capability rotation, stale URL invalidation, and ordered cleanup.
- The restart-before-forward rule: browser loss alone starts no child; the first later browser tool shares one bounded restart, the external lease remains stable, and waiting tools reach only the ready replacement exactly once.
- The stable typed HTTP error contract, fixed local WebSocket close pairs, request/response/header/connection/message/queue/timeout/shutdown limits, and redaction guarantees.
- Caller-owned MCP/CDP coordination and destructive raw `Browser.close` behavior.
- Client-specific disconnect guidance matching Packet 07 observations exactly; do not infer `browser.close()` semantics.
- A concise durable architecture flow with stable searchable entry-point symbols, not task history or unstable source line numbers.
