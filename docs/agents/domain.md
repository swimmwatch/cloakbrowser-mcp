# Domain Docs

This repository uses a single-context layout.

## Before exploring

- Read the root `GLOSSARY.md`, when present.
- Read relevant decisions under `docs/adr/`, when present.

If these documents do not exist, proceed silently.
Create them lazily through domain modelling when actual terms
or decisions are resolved; setup creates no placeholder documents.

## Vocabulary

Use terms defined in the glossary rather than competing synonyms.
Raise relevant terminology gaps when they affect the current task.

## Decisions

Surface conflicts with an existing ADR explicitly.
Get a decision before treating a conflicting proposal as accepted.
